# Midnight Forest（暗黑森林）色彩架構規範

本文件為 **Oh My PPT (SanHsien 維護版)** 專屬原創的深色主題色彩架構標準，為客戶端 UI 元件、表單控制項、圖表與提示對話框之視覺設計單一真相源。

---

## 一、設計哲學 (Design Philosophy)

1. **有機沉浸（Organic Immersion）**：
   延續 Oh My PPT 獨特之自然植物系與低飽和大地美學，拒絕生硬刺眼的純黑（`#000000`）底色，採用深苔墨綠（`#111411`）營造靜謐舒適的夜間創作環境。
2. **表面高度層級（Elevation Hierarchy）**：
   深色模式必須依賴清晰的 Z 軸表面明度階梯來界定空間深度，使畫布、側欄、內容卡片、可填寫控制項與浮動彈窗之間具備直觀層次。
3. **無障礙高對比度（WCAG AAA Accessibility）**：
   文字前景色階嚴格與其所在的底色建立對比，避免「白底白字（表面反轉失敗）」或「暗底暗字（文字難辨）」，文字對比度保證在 5.2:1 至 13:1 以上。

## 二、表面高度層級規範 (Surface Elevation System)

```text
┌────────────────────────────────────────────────────────────────────────┐
│                        五級表面深度體系 (Elevation)                    │
├─────────┬──────────────┬────────────┬──────────────────────────────────┤
│ 層級    │ 適用區域     │ 色碼 / 數值│ 視覺特性與功能描述               │
├─────────┼──────────────┼────────────┼──────────────────────────────────┤
│ Level 0 │ 畫布最底層   │ #111411    │ 應用程式整體背景，消除長時間疲勞 │
│ Level 1 │ 側邊導航欄   │ #151A14    │ 與主工作區形成微明度區隔         │
│ Level 2 │ 內容卡片/面板│ #191F18    │ 承載設定、統計與列表等區塊       │
│ Level 3 │ 表單控制項   │ #20291F    │ 輸入框 (Input)、下拉框 (Select)  │
│ Level 4 │ 浮動視窗/通知│ #222C21    │ 提示 Toast、下拉選單浮層、對話框 │
└─────────┴──────────────┴────────────┴──────────────────────────────────┘
```

- **容器凹陷感與凸起感**：
  - Level 3 控制項（如輸入框、SelectTrigger）使用內陰影 `inset 0 1px 3px rgba(0,0,0,0.35)`，呈現清楚的「可填寫凹槽感」。
  - Level 4 浮層使用外擴陰影 `0 16px 38px rgba(0,0,0,0.6)`，與下層內容形成明確浮動區隔。

## 三、前景色階與對比度矩陣 (Typographic Contrast Matrix)

| 色階角色 | 色碼數值 | 適用場景 | 對比度 (Level 2/3) |
|---|---|---|---|
| **主前景色 (Primary)** | `#F2F7ED` | 大標題、輸入框填寫值、選單當前項目、啟用標籤 | **> 13:1 (符合 AAA)** |
| **次前景色 (Secondary)** | `#CDD9C7` | 卡片副標題、說明內文、列表文字 | **> 9:1 (符合 AAA)** |
| **標籤與輔助 (Muted)** | `#A4BBA0` | 未選中分頁、輔助提示、次級描述文字 | **> 5.2:1 (符合 AA)** |
| **佔位符 (Placeholder)** | `#8EA383` | 未輸入之提示文字 (如「請先選擇儲存目錄」) | **> 4.5:1 (清晰可辨)** |
| **啟用中強文字 (Active)** | `#FFFFFF` | 啟用狀態之膠囊標籤、主要按鈕文字 | **極限對比度** |

## 五、互動狀態與按鈕 (Interactive Controls)

1. **分頁標籤（Tabs）**：
   - 容器（`TabsList`）：Level 1 深色基底（`#141913`），具備柔和微描邊。
   - 啟用中項目（`TabsTrigger[data-state=active]`）：深綠底色 `#364E2D` + 純白文字 `#FFFFFF` + 細緻描邊 `#547348`。
   - 未選中項目：文字呈現鼠尾草灰綠 `#A2B89D`，滑鼠懸停時平滑提亮至純白。
2. **下拉選單（Select）**：
   - 觸發框（`SelectTrigger`）：Level 3 深色槽 `#20291F`，文字為高對比度純白 `#FFFFFF`。
   - 選項（`SelectItem`）：選取項標記綠底 `#3B5232` 與純白文字，鍵盤聚焦時平滑反白。
3. **操作按鈕（Buttons）**：
   - 主要按鈕（Primary）：經典漸層 `from-[#6F8159] to-[#4F613F]`，文字純白。
   - 次要按鈕（Secondary）：深色模式切換為沉穩墨綠 `from-[#5D7C4F] to-[#415A35]` 配白字與描邊。

## 六、樣式代碼實作指引

- 全域樣式實作位於 [`src/renderer/src/index.css`](../src/renderer/src/index.css)。
- 元件撰寫時避免使用硬編碼之淺色類別（如 `bg-[#fff9ef]`、`text-[#3e4a32]`）；若舊上游元件包含這些類別，必須在 `index.css` 中以 `.dark` 規則完成層級映射。

## 七、風格庫與範本展示卡片專用規範 (Style & Template Cards)

為徹底解決深色模式下卡片文字發灰、混濁的視覺缺陷，本主題對風格庫與範本卡片訂定以下強制規範：

1. **消滅半透明白底 (No Translucent White on Dark)**：
   - 原上游使用 `bg-white/70` 疊加於深色畫布，會產生灰白霧化塊狀感。
   - 深色模式下全面改為固態 Level 2 表面 `#192018`，搭配細緻深翠外框 `#33462f`。
2. **風格卡片文字三階對比**：
   - **風格主標題**（如「玫瑰松」、「瑞士網格」）：強制粗體高亮白 `#FFFFFF`（極限對比度）。
   - **副標題與類別**（如「深色 · 科技 · builtin」）：清晰薄荷亮綠 `#A8C29E`（資訊層級分明）。
   - **多行描述文字**（如「暗紫森林裏玫瑰靜默綻放...」）：高明度亮灰綠 `#E0EBE0`（對比度 >10:1，杜絕暗淡難讀）。
3. **標籤與功能徽章**：
   - 用途篩選 Chip 與風格標籤採用深綠黑基底 `#243322` 配清晰字體 `#CCE2C6`。
   - 「支援生圖」標記採用翡翠微光底 `#20361D` 配翡翠綠字 `#A6F0B4`。
4. **範本操作按鈕**：
   - 次級操作（`tone="subtle"`，如「匯入 PPTX 為模板」）深色模式下切換為深翠基底 `#1E271D` 配純白文字 `#F2F7ED`，消滅突兀白底。
